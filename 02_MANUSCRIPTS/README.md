# Manuscripts

This directory contains the primary narrative text for the **Somatic Canticles** trilogy.

## Canonical Source

`02_MANUSCRIPTS/COMPILED/` is the manuscript source of truth for the trilogy.

- `CHAPTERS/` contains the chapter-by-chapter working corpus.
- `COMPILED/` contains the canonical clean book files and omnibus assembled from the working corpus.
- `CLEAN/` is deprecated and should not be treated as an active manuscript source.
