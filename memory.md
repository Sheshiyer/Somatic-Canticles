## Error Patterns and Solutions
- **Status drift in top-level docs**: legacy plans and completed production tasks can outlive the current operating state.
  - **Solution**: anchor top-level copy to `SC_STORYOPS/story/clarify_log.md`, `SC_STORYOPS/story/README.md`, and canonical chapter summaries before making readiness claims.
- **File offsets**: line numbers become unreliable in rapidly changing manuscript surfaces.
  - **Solution**: use semantic phrase search and current authority docs rather than stale references.
