# SWA-011 Contract: Pilot Objective and Success Metrics

## Objective
Build a non-editorial, provenance-safe, multilingual knowledge network pilot that can retrieve high-density tree-node relationships across biofield charts, interpretation maps, and cross-integration histories.

## Success Metrics
- Retrieval quality: top-line weighted score from approved rubric
- Cross-language reliability: stable match behavior on multilingual queries
- Hierarchy coherence: correct parent-child and sibling neighborhood behavior
- Provenance fidelity: every retrieved node points to valid source evidence

## Pass Criteria
- Pilot metrics package is complete for both text models and VL lane
- Decision threshold rule can be evaluated from recorded metrics
- No unresolved schema blockers remain from Phase 1 contracts
