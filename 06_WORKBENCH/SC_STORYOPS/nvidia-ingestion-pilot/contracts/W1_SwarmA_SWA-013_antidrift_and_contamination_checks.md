# SWA-013 Contract: Anti-Drift and Contamination Checks

## Drift Controls
- Block lexical drift into unsupported ontology terms.
- Block relation inflation without supporting evidence.
- Block cross-language false positives from noisy transliterations.

## Contamination Controls
- Never write pilot outputs into canonical manuscript folders.
- Never mutate editorial doctrine files from pilot tooling.
- Require boundary-policy check before wave transitions.

## Gate Checks
- Path-scope validation passes for all generated artifacts.
- Canonical zone remains unchanged across pilot runs.
- Quarantine queue is empty or explicitly justified before phase exit.
