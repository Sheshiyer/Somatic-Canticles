# SWA-024 Contract: Hierarchy Coherence Scoring Guide

## Score Anchors (0-5)
- `0`: neighbors unrelated to node context
- `1`: weak local overlap, no parent-child signal
- `2`: partial thematic overlap, unstable hierarchy
- `3`: mostly coherent neighborhood with minor noise
- `4`: strong parent-child and sibling coherence
- `5`: highly coherent neighborhood, minimal noise

## Evidence
- Include query id, returned node ids, and parent expectation.
