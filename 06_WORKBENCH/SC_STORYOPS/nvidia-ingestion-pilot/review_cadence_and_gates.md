# Review Cadence and Decision Gates

## Cadence
- Daily async check: artifact and blocker update
- Weekly sync: wave checkpoint review
- End-of-wave gate: explicit pass/fail with evidence

## Gate Template
- Scope completed
- Acceptance checks passed
- Validation evidence attached
- Risks updated
- Next wave unlocked

## Required Gate Artifacts
- Updated `tasks/todo.md` state
- Wave checkpoint markdown
- Validation output references
