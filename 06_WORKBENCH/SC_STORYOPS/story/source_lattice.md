# Source Lattice

## Purpose

This file maps the trilogy intake domains that should support future scene work. Chapter-level assignment is downstream from this file, not the starting point.

Legend:

- `P`: project-local manuscript/editorial source
- `W`: world-bible source
- `R`: `03-Resources` source
- `N`: external Noesis research source
- `B`: adjacent blog synthesis source
- `V`: visual family or asset anchor

## Operating Rule

- First map source families to concepts.
- Then project concepts into books.
- Only after that should chapters inherit source packs.
- All `W` sources below inherit their safe-use posture from `intake/world_bible_authority_registry.md`; directory presence alone does not make a file hard authority.
