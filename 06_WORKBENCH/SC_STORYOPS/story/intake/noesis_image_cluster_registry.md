# Noesis Image Cluster Registry

## Purpose

This file turns the external Noesis image corpus into retrievable semantic clusters before those images are pushed into book lanes.

The goal is not exhaustive captioning. The goal is to identify recurring visual families that can support concept extraction, editorial mapping, and eventually chapter packets.
