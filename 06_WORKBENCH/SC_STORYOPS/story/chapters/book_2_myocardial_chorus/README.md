# Book 2 Workbench

This folder stages Book 2 material only after trilogy-wide intake is ready to project into a book lane.

- `working/` contains copied source chapters from `02_MANUSCRIPTS/CHAPTERS/BOOK_2_THE_MYOCARDIAL_CHORUS/`.
- `packets/` contains the compact edit packets required before any prose pass.

Rules:

1. Treat this folder as a provisional downstream lane, not as the governing scope of `SC_STORYOPS`.
2. Do not expand or revise Book 2 packeting until the trilogy-wide intake layer justifies the assignment.
3. Do not edit `working/` without consulting the corresponding packet.
4. Any future rewrite or line pass must update the packet first if the source logic changes.
5. A merge-back to canon must compare staged work against the current compiled Book 2 text, not only against the copied chapter source.
