# SC_STORYOPS Story Workspace

This folder is a staging lane for the trilogy-wide `v0.2` intake pass: research extraction, image principle extraction, lore/worldbuilding consolidation, dialogue calibration, and later chapter-packet prep.

It is intentionally separate from the canonical manuscript surfaces:

- `02_MANUSCRIPTS/COMPILED/` is the canonical release text.
- `02_MANUSCRIPTS/CHAPTERS/` is the source chapter corpus for future working copies.
- `06_WORKBENCH/SC_STORYOPS/` is the isolated place to clarify, map, and prepare edits before anything returns to canon.

## Working Contract

1. Never draft directly in `02_MANUSCRIPTS/COMPILED/`.
2. When a chapter enters this workbench, copy it from `02_MANUSCRIPTS/CHAPTERS/`, not from the omnibus.
3. Every future prose edit must cite:
   - a chapter packet,
   - supporting source references,
   - dialogue constraints from `dialogue_voice_matrix.md`,
   - and the active rules in `book_rules.md`.
4. This workbench is where narrative, research, image, and downstream visual drift gets resolved before any merge back to canon.
5. The active sequence for this cycle is:
   - `/clarify`
   - trilogy-wide intake
   - `/plan`
   - `/tasks`
   - only then book or chapter assignment
