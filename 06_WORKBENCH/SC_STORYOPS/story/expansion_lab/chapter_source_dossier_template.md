# Chapter Source Dossier Template

Use one copy of this template per chapter before expansion drafting begins.

## 1. Chapter Identity

- `Chapter`
- `Book`
- `Current working file`
- `Current compiled file`
- `Current word count`
- `Target word band`

## 2. Canon Function

- chapter summary from `chapter_summaries.md`
- trilogy role in the larger beat chain
- inbound carryover from the previous chapter
- outbound obligation to the next chapter

## 3. Character-Arc Obligations

For each active character in the chapter:

- sacred flaw pressure
- want vs need tension
- required local change or refusal
- lines from `TRILOGY-CHARACTER-ARCS.md` that must remain true

## 4. Story Layer Diagnosis

Rate each layer as `strong`, `adequate`, or `under-served`:

- meaning
- character change
- plot
- mystery
- world
- relationships
- prose

Then note:

- what currently feels rushed
- what currently feels dry
- what currently feels over-explained
- what currently feels under-contextualized

- synchronocities-blog posts
- `03-Resources` files

## 8. Multimodal Evidence

If image or diagram material is used, record:

- image path or asset path
- extraction model used
- motif summary
- symbolic pressure
- biological or governance hook
- chapter beat where it may appear
- whether it stays atmospheric, metaphorical, or structural

## 8a. Implicit Symbolic Scaffold

If the chapter is using the endocrine / Nine Muses / enneagram / tarot lattice, record:

- whether the scaffold is active in this chapter
- the symbolic function it is serving
- Toth/Crowley deck basis or equivalent legacy translation note
- zodiac or archetypal correspondences that matter for tone or pacing
- which symbolic elements stay submerged in scene architecture rather than spoken aloud
- what would count as over-explicit or sermonizing misuse

## 9. Scene Growth Opportunities

List the best expansion opportunities:

- opening pressure extension
- relational aftermath
- sensory/somatic dwell time
- lore embodiment through scene behavior
- mystery plant or delayed reveal
- world-pressure insertion
