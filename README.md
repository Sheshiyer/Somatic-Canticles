# Somatic Canticles

> *"The universe is not made of atoms; it is made of stories. Atoms are just the ink."*

**Somatic Canticles** is a sci-fi trilogy about consciousness, embodiment, and authored reality. This repository holds the canonical manuscript surfaces, the world-bible and editorial authority layers, and the isolated `SC_STORYOPS` workbench used to map research and image inputs before any future prose changes return to canon.

## Repository Structure

### [01_WORLD_BIBLE](./01_WORLD_BIBLE/)
The governing lore, systems, character, and worldbuilding layer.

### [02_MANUSCRIPTS](./02_MANUSCRIPTS/)
The canonical trilogy text and source chapter corpus.
- `COMPILED/`: canonical export surfaces
- `CHAPTERS/`: chapter-source files for downstream staging

### [03_EDITORIAL](./03_EDITORIAL/)
Editorial doctrine, terminology, style, and calibration materials.

### [04_SOURCES](./04_SOURCES/)
Research and reference inputs used to support the project.

### [05_DIGITAL_ASSETS](./05_DIGITAL_ASSETS/)
Visual, web, and supporting digital artifacts.

### [06_WORKBENCH](./06_WORKBENCH/)
Staging space for non-canonical prep work, including `SC_STORYOPS`.

## Current Canon

- The trilogy currently has **27 canonical chapters** across three books.
- The **22-card arcana layer** remains a visual and conceptual taxonomy.
- Arcana is **not** currently a one-to-one chapter-count contract.

## Project Status

- **Current phase**: trilogy-wide `v0.2` intake and mapping in `06_WORKBENCH/SC_STORYOPS/`
- **Readiness**: `canon/export ready`
- **Open gap**: `research/image mapping incomplete`

That means the canonical manuscript and export surfaces are usable, but the workbench is still consolidating source, lore, and image support before any broader release-readiness claim is warranted.
