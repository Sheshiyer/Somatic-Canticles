# Tasks Workspace

This directory is the active operations surface for repository planning and execution.

## Source Of Truth

- `tasks/todo.md`: active task tracker, current execution order, and short review notes
- `tasks/lessons.md`: recurring mistakes, prevention rules, and startup reminders
- `memory.md`: historical context and prior outcomes; useful background, not the active task board

## Use Rules

- Put all non-trivial active work in `tasks/todo.md`.
- Capture repeatable mistakes and prevention rules in `tasks/lessons.md`.
- If an older planning document is kept for history, mark it historical or superseded instead of letting it compete with `tasks/todo.md`.
